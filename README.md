## ✨ Highlights

- **⚡ High-Speed Gemini Vision OCR**: Direct async REST integration with Google Gemini's multimodal vision API for sub-second, regex-free license plate extraction.
- **🔄 Intelligent Model Fallback**: Prioritizes `gemini-3.5-flash-lite` for blazing-fast inference with transparent failover to `gemini-3.5-flash`.
- **🗄️ Supabase REST Persistence**: Directly persists plate text, confidence tags, and timestamps via Supabase REST API without bulky client SDK cold starts.
- **🎨 Modern Glassmorphic Dark UI**: Drag-and-drop vehicle photo uploader, real-time image preview, animated status indicators, and one-click scan trigger.
- **🚀 Vercel Zero-Config Architecture**: Static HTML served at root `/` with serverless Python ASGI functions automatically routed at `/api/*`.
- **🛡️ Public-Ready Security**: 100% credential-sanitized with zero hardcoded tokens, dynamic environment variable loading, and hardened `.gitignore`.

## 🚀 Quick Start (Local Development)

### 1. Clone & Navigate
```bash
git clone https://github.com/<your-username>/visual_recognition_studio.git
cd visual_recognition_studio
```

### 2. Set Up Virtual Environment & Dependencies
```bash
python -m venv .venv
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Configure Environment Variables
Copy the template and fill in your keys:
```bash
cp .env.example .env
```

Edit `.env`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key_here
```

> **Where to get keys:**
> - **Gemini API Key**: [Google AI Studio](https://aistudio.google.com/)
> - **Supabase URL & Service Role Key**: [Supabase Dashboard](https://supabase.com/dashboard) → Project Settings → API

### 4. Database Setup (Supabase)
Run the following SQL in the **Supabase SQL Editor** to create the table:
```sql
CREATE TABLE IF NOT EXISTS plate_reads (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    plate_text TEXT NOT NULL,
    confidence TEXT DEFAULT 'gemini-3.5-flash-lite',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
```

### 5. Run the Local Development Server
```bash
uvicorn main:app --reload --port 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### 6. Verify via CLI
In a separate terminal:
```bash
python test_upload.py test_car.jpg
```

## ☁️ Vercel Deployment

Deploy with one click or via the Vercel CLI:

1. Push this repository to GitHub.
2. In the [Vercel Dashboard](https://vercel.com/dashboard), click **"Add New..." → "Project"** and import this repository.
3. Keep default build settings (**no custom build command needed**).
4. Add the following **Environment Variables** in the Vercel deployment modal:

| Variable | Description | Source |
|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio API key | [Google AI Studio](https://aistudio.google.com/) |
| `SUPABASE_URL` | Supabase project URL (`https://<id>.supabase.co`) | Supabase Settings → API |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service-role secret key | Supabase Settings → API |

5. Click **Deploy**. Vercel will build the static frontend at `/` and serverless Python endpoints at `/api/*`.

## 📡 API Reference

### Health Check
- **Endpoint**: `GET /api` or `GET /api/index`
- **Response**:
```json
{
  "status": "online",
  "service": "ALPR Serverless",
  "gemini_configured": true,
  "supabase_configured": true
}
```

### Recognize License Plate
- **Endpoint**: `POST /api/recognize_plate` (or `POST /recognize-plate`)
- **Body**: `multipart/form-data` with form field `file` containing an image (JPEG, PNG, WebP).
- **Response**:
```json
{
  "plate_text": "777ABC01",
  "db_success": true,
  "message": "Record inserted successfully."
}
```
